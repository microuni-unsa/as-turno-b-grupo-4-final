Arquitectura Integral del Sistema PIMS (ISO/IEC 27701:2025)

1. Ingress & TLS Edge

Traefik Edge Proxy
Terminación TLS / HTTPS / WSS en incidents-pims.mistercricro8.top con proxy reverso seguro.

2. Glass-Box Cockpit

Astro v5 Framework
Server-First MPA & SSR para vistas de cumplimiento (/compliance), incidentes y auditoría.
Tailwind CSS + Starwind UI
Sistema de componentes accesibles de alta fidelidad visual.
Web Speech API (Browser)
Dictado por voz local en el navegador sin persistencia de audio ni streaming externo.
Server-Sent Events (SSE)
Canal unidireccional /api/stream para trazas de pensamiento del agente y reloj de 72h.

3. Backend API & Daemon

Bun Runtime v1.4.x
Ejecución nativa TypeScript, gestión de monorepo workspaces y empaquetado de alta velocidad.
Hono API Server
Endpoints REST para mutación de incidentes, sesiones y canal SSE backend.
TypeScript + Zod
Validación fail-fast y tipado estricto en todos los contratos y herramientas.
Autonomous Watcher Daemon
Sondeo continuo a PIMS, control de leases de concurrencia y bloqueo por hash de propuesta.
Countdown Scheduler (72h)
Cuenta regresiva para notificación a la autoridad según GDPR Art. 33.

4. Privacidad & RAG

Microsoft Presidio Sidecar
FastAPI + spaCy es_core_news_md con reconocedores de DNI y RUC peruanos.
AgentModelClient Gate
Filtro fail-closed: si el sidecar falla, aborta inmediatamente con PII_REDACTION_UNAVAILABLE.
pgvector Semantic Store
Búsqueda semántica densa de cláusulas ISO 27701 y artículos del GDPR en 1536 dimensiones.
MiniSearch BM25 Léxico
Búsqueda léxica exacta en español para términos regulatorios específicos.
RRF & Cross-Encoder
Fusión denso-dispersa y re-clasificación semántica con citas normativas verificables.

5. Persistencia & PIMS

PostgreSQL 17 + Drizzle ORM
Almacén relacional de evidencias, leases y datos operativos con esquemas tipados.
AES-256-GCM Blob Storage
Cifrado en reposo para archivos probatorios confidenciales con confinamiento de rutas.
Forensic SHA-256 Sealer
Sellado canónico de bundles JSON y firmas criptográficas inmutables.
GESTITEL PIMS Server / Adapter
Adaptador de cliente HTTP que conecta con los endpoints reversados E01 a E26.

6. Plataforma & DevOps

Docker & Microdev
Definición tipada de servicios compartida entre tests de integración y producción.
Nix Flake Hermético
Toolchain 100% reproducible: bun, postgresql-17, sops y typst.
